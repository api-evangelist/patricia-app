Patricia provides an AI coworker platform tailored for small marketing agencies, automating client reporting, campaign management, meeting notes, and administrative tasks. The service integrates with major ad and analytics platforms such as Google Ads, Meta, LinkedIn, and tools like Notion, Asana, and Salesforce, offering a unified interface to streamline agency workflows. Pricing is subscription‑based per agency seat, with usage credits for AI‑generated content. Security features include scoped access, audit logs, and data deletion on cancellation, ensuring client data remains private.

**Areas:** Marketing · Agency Tools · Client Reporting · Integrations

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Patricia: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
